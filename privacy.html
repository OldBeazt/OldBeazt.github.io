Privacy Policy

Dad's Help Desk Analytics is a private tool used only by the owner of the Dad's Help Desk YouTube channel.

  • What it accesses: read-only YouTube Analytics and channel data for the owner's own channel, through Google's YouTube APIs, with the owner's consent.
  • How it is used: to produce performance reports for the channel's own videos.
  • Storage: data is stored only on the owner's own computer. It is not sold, shared or transferred to anyone.
  • Other users: the tool does not collect data about viewers or any other person beyond the aggregate statistics YouTube Analytics provides to channel owners.
  • Revoking access: access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy.

Contact: through the Dad's Help Desk YouTube channel.
